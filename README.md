# Quiz Management System

**Project Code:** CPP53
**Enrollment Number:** IU2541230517
**Language:** C++

## Project Overview

A console-based C++ application for managing multiple-choice questions, conducting quizzes, calculating scores, and saving records using file handling.

## Features

* Add, display, search, update, and delete questions
* Conduct quizzes and calculate scores
* Display quiz reports
* Save and load question and attempt data
* Basic input validation and exception handling

## Object-Oriented Programming Concepts

* Classes and objects
* Encapsulation
* Constructors and destructors
* Inheritance
* Runtime polymorphism
* Dynamic memory allocation
* File handling

## Project Structure

* `Source/` — C++ source and header files
* `Data/` — Question and attempt records
* `Diagrams/` — UML diagrams
* `Screenshots/` — Program screenshots
